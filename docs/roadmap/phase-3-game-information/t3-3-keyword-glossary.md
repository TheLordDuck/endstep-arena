## What exists now

The enlarged card shows the card's text, but doesn't explain keywords.

## What it involves

- Boxes beside the enlarged card explaining each keyword it has (including ones granted by effects), as Arena does.
- A table of texts for the common keywords.

## Done when

- Enlarging a card with keywords shows what each one does.
